# Extensions (after the Phase 2 submission)

This folder is personal work I did after submitting the Phase 2 Algorithmic Contribution. It extends the theory behind scale separation. It is not part of the submission, which is the rest of this repository at the tag `phase2-submission`. I share it in case it is useful to ARC.

| file | what it is |
|---|---|
| `THEOREM.md` | theorems and proofs behind the method, and a list of what is not yet proved |
| `verify_theorem.py`, `verify_theorem.log` | numerical checks of every statement in THEOREM.md (about 15 seconds on a CPU) |
